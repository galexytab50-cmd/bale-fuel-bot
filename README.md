# بات محاسبه‌گر صرفه‌جویی سوخت (بله) — روی Cloudflare Workers

بات پیام‌رسان بله (Bale) که با پرسیدن مدل خودرو، کیلومتر روزانه، روزهای رانندگی
در هفته و سبک رانندگی، تخمین صرفه‌جویی حاصل از تبدیل خودرو به گازسوز رو محاسبه
می‌کنه.

این نسخه با **TypeScript** نوشته شده و روی **Cloudflare Workers** اجرا می‌شه —
به‌صورت webhook (نه polling)، چون Workers محیط request/response هست.

## وضعیت فعلی

اسکلت کامل مکالمه (فلوی پرسش و پاسخ) آماده و تست شده (`tsc --noEmit` بدون خطا
رد می‌شه). اعداد مصرف سوخت هر خودرو، قیمت بنزین/گاز و فرمول دقیق محاسبه هنوز
باید تکمیل بشه (بخش‌های `TODO` داخل `src/index.ts`).

## پیش‌نیازها

- [Node.js](https://nodejs.org) نسخه ۱۸ یا بالاتر
- یک اکانت رایگان [Cloudflare](https://dash.cloudflare.com/sign-up)
- یک توکن بات از بله (راهنمای گرفتنش پایین‌تر هست)

## مرحله ۱: گرفتن توکن بات از بله

۱. توی اپ بله، بازوی **BotFather@** رو جستجو کن
۲. بزن «شروع» → «ساخت بازوی جدید»
۳. یک اسم دلخواه بده (مثلاً «محاسبه‌گر سوخت»)
۴. یک آیدی یکتا انتخاب کن که با `bot` تموم بشه (مثلاً `mysavingbot@`)
۵. توکنی که برات ارسال می‌شه رو یه جای امن نگه دار

## مرحله ۲: نصب و ورود به Cloudflare

```bash
git clone <آدرس-ریپوی-شما>
cd bale-fuel-bot-ts
npm install

# ورود به اکانت Cloudflare (یه تب مرورگر باز می‌شه)
npx wrangler login
```

## مرحله ۳: ساخت KV Namespace

بات برای نگه‌داشتن وضعیت مکالمه هر کاربر (اینکه الان توی چه مرحله‌ایه) از
Cloudflare KV استفاده می‌کنه:

```bash
npx wrangler kv namespace create BOT_STATE
```

خروجی این دستور چیزی شبیه این می‌ده:

```
[[kv_namespaces]]
binding = "BOT_STATE"
id = "abcd1234..."
```

مقدار `id` رو کپی کن و داخل فایل `wrangler.toml` جایگزین `YOUR_KV_NAMESPACE_ID`
کن.

## مرحله ۴: تنظیم توکن بات

**برای سرور واقعی Cloudflare** (secret، امن و رمزنگاری‌شده):

```bash
npx wrangler secret put BALE_TOKEN
# توکن رو وقتی خواست پیست کن و اینتر بزن
```

**برای تست لوکال روی سیستم خودت** (اختیاری):

```bash
cp .dev.vars.example .dev.vars
# سپس .dev.vars رو باز کن و BALE_TOKEN رو پر کن
```

## مرحله ۵: دیپلوی روی Cloudflare

```bash
npx wrangler deploy
```

بعد از اجرا، یک آدرس شبیه این بهت می‌ده:

```
https://bale-fuel-bot.<your-subdomain>.workers.dev
```

این آدرس رو کپی کن، لازمش داری برای مرحله بعد.

## مرحله ۶: وصل کردن Webhook بله به Worker

باید به بله بگی هر پیام جدید رو به آدرس Worker بفرسته. این کار با یک درخواست
ساده HTTP انجام می‌شه (کافیه این آدرس رو یک بار توی مرورگر یا ترمینال باز کنی):

```bash
curl "https://tapi.bale.ai/bot<TOKEN>/setWebhook?url=https://bale-fuel-bot.<your-subdomain>.workers.dev"
```

جای `<TOKEN>` توکن بات و جای آدرس Worker همون آدرسی که مرحله قبل گرفتی رو بذار.

اگه جواب `{"ok":true,...}` گرفتی یعنی وصل شد! حالا برو تو بله سراغ بات خودت و
`/start` رو بزن.

## تست لوکال (قبل از دیپلوی نهایی)

```bash
npm run dev
```

این یک سرور لوکال بالا میاره؛ برای تست واقعی وبهوک نیاز به یک URL عمومی داری
(مثلاً با [ngrok](https://ngrok.com))، پس معمولاً ساده‌تره مستقیم دیپلوی کنی و
با `wrangler tail` لاگ‌های زنده رو ببینی:

```bash
npx wrangler tail
```

## ساختار فلوی مکالمه

1. `/start` → نمایش لیست مدل‌های خودرو
2. انتخاب خودرو → پرسیدن کیلومتر روزانه (۵ تا ۱۵۰)
3. کیلومتر روزانه → پرسیدن روزهای رانندگی در هفته (۱ تا ۷)
4. روزهای هفته → پرسیدن سبک رانندگی (آرام / معمولی / تند)
5. نمایش نتیجه محاسبه

برای لغو مکالمه در هر مرحله: `/cancel`

## چرا webhook به‌جای polling؟

Cloudflare Workers یک محیط serverless و request/response هست — کد فقط وقتی
اجرا می‌شه که یک درخواست HTTP بهش برسه، و نمی‌تونه به‌صورت دائم در پس‌زمینه در
حال اجرا بمونه (مثل چیزی که با polling لازمه). به همین خاطر به‌جای اینکه بات
مدام از بله بپرسه «پیام جدید داری؟»، خود بله با هر پیام جدید مستقیماً به آدرس
Worker درخواست می‌فرسته.
